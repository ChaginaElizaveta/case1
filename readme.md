graph TD
    A[Вы вводите пароль] --> B[JS запрашивает соль у Python]
    B --> C[Python отдает соль из БД]

    D --> E[Получается хеш]
    E --> F[Отправляем хеш в Python]
    F --> G[Python сравнивает хеши]

### PBKDF2 = Пароль + Соль + Итерации + Алгоритм хеширования SHA256

### SHA256:
    Входные данные 
    --> Добавление паддинга 
    --> Разбивка на блоки по 512 бит 
    --> Инициализация 8 констант 
    --> Для каждого блока 
    --> 64 раунда преобразований 
    --> Сложение с предыдущим хешем 
    --> Финальный хеш 256 бит
